# AI Tools Lab

A small Python project for the AI Tools and Applications Lab (AGCS-25308). It contains a sorting algorithm and a few handy utility functions, and it was built to practise Git, GitHub and AI-assisted coding.

## Project Description

- **Sorting algorithms:** `sorting.py` has a bubble sort function.
- **Utility functions:** `utils.py` has `is_palindrome`, `count_words` and `celsius_to_fahrenheit`, each with a docstring.

## Installation

1. Make sure Python 3 is installed.
2. Clone the repository:

```bash
git clone https://github.com/sanyam-netizen/Ai-tools-lab.git
cd Ai-tools-lab
```

No extra libraries are needed.

## Usage

Run the sorting example:

```bash
python sorting.py
```

Use the utility functions in your own code:

```python
from utils import is_palindrome, count_words, celsius_to_fahrenheit

print(is_palindrome("Madam"))             # True
print(count_words("AI tools lab"))        # 3
print(celsius_to_fahrenheit(100))         # 212.0
```
